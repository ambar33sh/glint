# Glint — Acdyon Part 2

A responsive product landing page built for the Acdyon Technologies Frontend Challenge.

## Run locally
```bash
npm install
npm run dev
```

Open the local Vite URL.

## Stack
- React
- Vite
- CSS
- Lucide icons

## Notes
The product concept is fictional. The page deliberately avoids fabricated customer testimonials, user counts, logos, or performance claims, in line with the assessment brief.

## Visual direction
The landing page uses a restrained glassmorphism system: translucent surfaces, backdrop blur, subtle borders, inset highlights, and ambient gradients while keeping text contrast and hierarchy strong.
